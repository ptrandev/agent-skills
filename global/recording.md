These personal preferences apply only when all three commands return the listed values:

| Command | Required value |
| --- | --- |
| `uname -s` | `Darwin` |
| `id -un` | `phillip` |
| `scutil --get LocalHostName` | `Phillips-MacBook-Pro-1577` |

**Do not apply these preferences on another machine or account.**
**Do not copy them into a project's `AGENTS.md`.**
If the machine identity is unavailable, do not assume that this rule applies.
Use the session's instructions on other machines.

On the matching personal MacBook:

- Identify the built-in display before opening a recording window.
- Do not assume that the primary display is built in.
- Open only windows needed for recording on the built-in display.
- Leave unrelated user windows alone.
- Keep the recording window inside the built-in display throughout recording.
- Capture the selected application window, never the whole display.
- Navigate and use the actual product for product walkthroughs.
- Do not substitute a screenshot deck for a product walkthrough.
- If display placement cannot be verified, stop before recording and report the limitation.
- Pass this file and its machine scope to every delegated agent, including Claude.
